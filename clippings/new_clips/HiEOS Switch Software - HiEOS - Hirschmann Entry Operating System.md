# Software Platform for Hirschmann LEMUR devices

As automation expands and industrial networks grow in complexity, easy-to-use network management technology that supports streamlined configuration and remote diagnostics is vital. The advanced HiEOS software runs on LEMUR lite managed switches, which are optimal for use in many industrial environments. With the HiEOS intuitive graphical user interface, switch setup and maintenance are easy – with little IT intervention or knowledge required. Also, HiEOS provides a rich feature set, including PoE/PoE+ support and device management. All relevant software files can be downloaded from the "Downloads" tab
