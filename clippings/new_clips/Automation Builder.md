## DISCOVER ENGINEERING PRODUCTIVITY

Automation Builder is ABB’s unified automation platform for PLCs, safety, drives, motion, and control panels — providing one engineering environment for the entire automation project.

Built on CODESYS and fully compliant with IEC 61131-3, it standardizes development across applications to simplify workflows and accelerate engineering.

![Focused worker in protective workwear at computer in factory ](https://media-d.global.abb/is/image/abbc/worker-in-protective-workwear:1x1-L)

### [Unify your engineering — one platform for all automation tasks](https://www.abb.com/global/en/areas/motion/digital-tools/automation-builder/engineering)

Improve productivity and accelerate commissioning by programming small, high-power, or safety PLCs, HMI panels, ABB drives, advanced communication, and motion control — all within a single engineering environment. By connecting all engineering tools in one ecosystem, you gain seamless collaboration, consistent project management, simplified maintenance, and reduced risks.

### [Boost your productivity — start free](https://www.abb.com/global/en/areas/motion/digital-tools/automation-builder/software-download)

Begin with a free Basic license, and upgrade to Standard or Premium to unlock integrated system engineering for PLCs, safety, drives, panels, redundancy, extended connectivity, and more. You’ll also gain advanced productivity and collaboration tools such as floating licenses, version control, Python scripting, and flexible configuration support.

	Automation Builder is ABB's integrated programming, simulation, commissioning and maintenance environment for PLCs, safety, drives, motion and control panels.

	Automation Builder is used for all of our AC500 PLCs and CP600 control panels, no matter if you have purchased the cost-efficient, high-end or safety versions.

	**ABB offers three different licenses, starting with the Basic license which is free of charge, and scaling up to the Standard and Premium licenses for more functionality and efficiency.

	### Device integration and programming

	Configure and program all devices in your automation solution within a single project, including third-party controllers and drives. Four IEC 61131 programming languages give engineers full flexibility and allow them to start programming immediately. State-of-the-art software development features, such as object-oriented programming, maximize engineering efficiency. The integrated version control system supports multi-user collaboration and advanced scenarios like product-line management.
