### Lightweight and portable cross-platform application

FUXA is very easy scalable from small projects using the Raspberry Pi up for visualization of large facilities.

It also offers powerful fully Web-Based new tools that allows you to create rich visualisations, data-logs, alarms, notifications, trends and remote device control in real-time.

### Connectivity - Included Device Connectors

It enables device connectivity via industry standard IoT protocols MQTT, OPC-UA, BACnet, Modbus, SiemensS7, WebAPI, ODBC, Ethernet/IP (Allen Bradley), ADS (Beckhoff), MC Protocol/SLMP (Mitsubishi), Redis, SNMP into one easy to use interface.

Low level protocols, like Serial or TCP, can enable you to interface with custom or proprietary protocols quickly.

### Alarms Management - Event Notification

Alarms can be enabled to monitor both analog and digital signals with fixed, adjustable and tracking alarm limits.

Forwards of messages (such as alarm messages or system information) to designated people.

### User management

User permissions are fully customizable by the system administrators, users are assigned to permission groups.

Groups can have very flexible permission levels from read-only to super-admin.

### Reporting

Reporting module embeded in FUXA, for reporting creation on the specified parameters in the PDF form.

Forwards of report to designated people.

### Scripting

Integrated code editor to define script in javascript language, the script can be schedule in server and client-side.

### Maps View using Leaflet for Geospatial Visualization

Visualize your data spatially with the Maps View feature powered by Leaflet. This tool enables real-time geospatial monitoring and representation, making it easier to track assets, operations, and more.

## FUXA can be used for the total building control system as well SCADA applications for Energy, Water Distribution, Manufacturing Plants, Laboratories...

## Most Important Features

- Toolbox for industrial web HMIs, web apps and dashboard apps
- Graphical Views Builder Fully drag & drop WYSIWYG development environment
- 100% pure web technology: HTML5, CSS, JavaScript, REST API and websocket communication
- HMIs and apps run in every HTML5-compliant web browser on a touch panel, PC, tablet or smartphone with no plugins required
- Connectivity: OPC-UA, Modbus RTU/TCP, MQTT, Siemens S7 Protocol, WebAPI, ODBC, Ethernet/IP (Allen Bradley), BACnet IP, ADSclient, Gpio (Raspberry), WebCam, MELSEC, Redis, SNMP (native fully customizable connection available as a service)
- Server runs on Windows, Linux and ARM architectures like Raspberry Pi, etc.
- SCADA functionality with integrated SQLite database engine: stores and displays huge amounts of process data as well as alarm events and context data
- User-based access with detailed permission settings

## FUXA Pro Features

The Pro version of FUXA includes a range of advanced features designed to enhance your experience in views design, process management and monitoring. Here are some of the key features:

![](https://frangoteam.org/assets/images/personalization.png)

### Customization of Label and Logo (White-Labeling)

Personalize your interface with custom labels and logos, ensuring a fully branded experience. Whether you’re creating dashboards for internal use or external clients, white-labeling provides the flexibility to align the interface with your company’s identity.

### Fonts as Resources

Load and use TrueType Fonts (TTF) for your views to achieve greater flexibility and customization in your design. Match the font styles with your branding guidelines or simply improve readability for end-users.

![](https://frangoteam.org/assets/images/fonts.png) ![](https://frangoteam.org/assets/images/tree-view.png)

### Tree View Organization for Views

Organize your HMI and SCADA views in a hierarchical tree structure using folders. This feature improves project navigation and clarity, especially in large-scale systems with many views. Group related screens by plant, process, or department for a more structured and efficient workspace.

### Configurable User Roles for Authorization

Enhance security and user management by replacing groups with configurable user roles. Assign specific permissions to roles for a more granular approach to system authorization and control.

![](https://frangoteam.org/assets/images/users-roles.png) ![](https://frangoteam.org/assets/images/events.png)

### User & Script Event Logging and Visualization

Capture and track user actions and script executions within FUXA. Easily view and analyze recorded events through a structured timeline and detailed logs. Enhance system monitoring and troubleshooting by filtering, exporting, and visualizing event data for better operational insights.

### AnyAutomation Studio

AnyAutomation Studio is a desktop engineering IDE for Siemens TIA Portal and CODESYS. It generates complete FUXA projects from a PLC's OPC UA address space, including devices, tags and screens, and provisions them directly onto a running FUXA instance.
