## Functions for the realization of professional control applications

- All IEC 61131-3 editors (FBD, LD, IL\*, ST, SFC), some of them in different variants (*\** *IL was marked as obsolete by PLCopen<sup>®</sup>, the IEC 61131-3 user organization, and is therefore no longer maintained. If required, IL can be enabled for use.*).
- Mature and tried-and-tested library concept for easy reuse of application code with available blocks, e.g. for communication with other systems.
- Project configuration using wizards and special editors.
- Input wizard, quick fixes and other smart coding options for fast input and configuration of a wide range of data.

- Convenient programming with mouse and keyboard in all IEC 61131-3 languages.
- Integrated compiler for fast application code for optimum utilization of controller performance - all CPU platforms for controllers supported.
- Comprehensive project comparison, also for graphical editors.
- Extensive debugging and online features for troubleshooting, optimizing the application code, and speeding up testing and commissioning, such as breakpoints, variable monitoring, sequence control.
- Extensive online and offline help at the touch of a button.
- Support for the most important national languages.
- Numerous security features for securing source code, communication and operation of control systems using certificates, dongles and passwords.
- Expandability and customizability of the interface via additional tools without leaving the product framework, including optional products to increase efficiency in application development and for continuous development.
- Project exchange via standardized (PLCopen XML) and proprietary formats.
- Simple archiving of complex projects.
- Programmable devices from a wide range of manufacturers and for a wide range of applications.
- Transparent internal structure of the programming tool and the associated components.
- Many seamlessly integrated tools for additional automation tasks, e.g. visualization, coordinated movements, redundancy, etc.
- Integrated access to online platforms, e.g. for reloading or installing optional or missing modules.

## Increase your output - object-oriented PLC programming

- Real object-oriented programming (OOP) according to 61131-3 3rd Edition in all IEC 61131-3 languages without additional tools
- Encapsulation of object-oriented program code in libraries with functional call interfaces: convenient provision of, for example, system functions or special algorithms for PLC programmers without knowledge of OOP
- Inheritance of program blocks to similar application parts to reduce development time and errors
- Object-oriented programming is not a must: Functional or object-oriented programming can be used and mixed as required.
