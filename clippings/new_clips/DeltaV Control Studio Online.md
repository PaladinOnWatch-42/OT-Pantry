## DeltaV™ Control Studio Online

With Control Studio Online, you can view your executing control strategies using the same graphical view that you used when you configured your strategies.

When online, this view updates with the actual running values. Control Studio Online provides operators and engineers with online information and graphically displays executing control strategies so you can modify parameters and troubleshoot in the same easy to use view.
