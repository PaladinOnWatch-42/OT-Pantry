The CODESYS HMI SL product is a software package that is installed on a remote computer (PC or panel) to equip it with a graphical user interface (HMI) that displays data from CODESYS V2, CODESYS V3, and OPC UA controllers. The visualization is created using the CODESYS Development System (V3), the free programming system with a fully functional visualization editor compliant with IEC 61131-3.
