## CODESYS Control SL

==CODESYS Control is the corresponding runtime system for the CODESYS Development System. It turns an intelligent device into a controller that can be programmed with the CODESYS Development System in the IEC 61131-3 languages==. Information on the technical features and functions of the runtime system can be found [here](https://us.codesys.com/products/runtime/ "CODESYS Runtime").

### Either:

You can select suitable controllers for your application from more than 1,000 different device types from over 500 manufacturers. These devices have already implemented CODESYS Control and can be programmed directly with the CODESYS Development System or manufacturer-specific derivatives.

### Or:

You can install the ready-to-use SoftPLC systems available in the [CODESYS Store](https://us.store.codesys.com/ "CODESYS Store") on the desired device platform yourself. With the appropriate license, you can activate all functions that are available in CODESYS.

## Free demo version with full functionality

**Test the SoftPLC conveniently and without risk:**

Install the appropriate SoftPLC on your target platform. If no valid license is found, it will automatically terminate after a runtime of 2 hours. You can restart the test period as often as you like by restarting the SoftPLC. You can access the full range of functions during the test period.

## Download and licensing of SoftPLC systems

The software is downloaded centrally via the [CODESYS Store](https://us.store.codesys.com/en/softplcs-for-applicationbased-licenses "SoftPLCs for application-based licenses"). Free registration is required for this.

The [licensing of the SoftPLC systems](https://us.store.codesys.com/en/licenses.html "CODESYS Store application-based licenses") depends on the application, i.e. the planned use and the desired scope of functions. Depending on the license purchased, additional functions are included, such as integrated support for fieldbus or real-time Ethernet systems, as well as the option of licensing the CODESYS optional products for visualization and motion control. [Here you will find an overview of the available platforms.](https://us.store.codesys.com/en/licenses.html "CODESYS Store application-based licenses")

## Advantages of the available SoftPLC systems

- Programming with the standard version of the CODESYS Development System: The latest versions with the latest features / bug fixes are always available - both for the development environment and for the SoftPLC.
- Execution of existing applications on a wide variety of SoftPLCs - without porting effort
- Extensibility of all SoftPLCs with the add-on products available in the CODESYS Store
- Integrated fieldbus support exclusively via software, especially for Ethernet fieldbuses:
	- EtherCAT® MainDevice
		- PROFINET controller / device
		- EtherNet/IP™ scanner / adapter
		- Extensibility via gateway terminals or PCI adapters

- Further additional functions integrated or optionally available, depending on the license and the properties of the hardware: e.g. OPC UA Server, CANopen <sup>®</sup> / J1939, Modbus, CODESYS WebVisu, CODESYS TargetVisu, CODESYS SoftMotion, CODESYS SoftMotion CNC+Robotics
- Extensibility of functionality using the free CODESYS Control Extension Package (see [CODESYS Runtime](https://us.codesys.com/products/runtime/ "CODESYS Runtime"))
- Consistent licensing based on the application parameters:
	- Identical licenses for all devices
		- Flexible range of functions, depending on your own requirements
		- Easy extensibility of the license type
