HiSecOS Firewall Software delivers security for industrial security routers. It provides the user with security mechanisms to protect networks against attacks and operating errors. Designed to fulfill IEEE 1686 standard requirements, functions such as audit trails and user management/password policies are implemented from the beginning.

### Features & Benefits

- Monitor & Filter Data Packets: Deep Packet Inspection (DPI) supports network protection from spam and viruses
- Analyze Network Traffic: Firewall Learning Mode (FLM) helps create rules, permitting desired traffic and discarding unauthorized packets
- Authorize Users: Lightweight Directory Access Protocol (LDAP) authenticates at a central point in the network
