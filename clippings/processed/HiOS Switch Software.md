## Hirschmann HiOS switch software

HiOS, the Hirschmann switch operating system, now runs up to four HSR rings on a single GRS 2000 or BRP switch, so high-availability networks no longer need a separate device for every ring. The capability follows IEC 62439-3 and is native to the hardware, so switches already running HiOS 2A or 3A add it through a firmware upgrade. HiOS also brings comprehensive security, Time-Sensitive Networking and an embedded OPC UA server across one operating system.

### Features & Benefits

- Run up to four HSR rings on a single GRS 2000 or BRP switch, cutting the redundancy hardware in the cabinet
- Secure industrial networks with comprehensive security, independently certified to IEC 62443-4-1
- Add HSR to installed HiOS 2A and 3A switches with a firmware upgrade, no new hardware required
- Bridge IT and OT with an embedded OPC UA server and Time-Sensitive Networking on a single operating system
- Keep networks online with seamless, zero-loss redundancy compliant with IEC 62439-3, including HSR and PRP
