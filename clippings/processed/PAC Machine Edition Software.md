## PAC Machine Edition v11.0 Now Available

The latest release of PAC Machine Edition strengthens Emerson's unified engineering environment for machine control, helping reduce complexity across the machine lifecycle.

New features and enhancements include:

- Significant core performance and stability improvements over previous iterations.
- Native configuration and runtime support for the new QuickPanel+2 HMI, enabling existing users to easily migrate QuickPanel+ projects within PAC Machine Edition.
- An upgraded internal PLC/controller simulation engine for offline testing.
- Expanded access to change history and audit trails through native PAC Change Management software integration.

In addition, PAC Machine Edition v10.6 introduced:

- A built-in Simulator that empowers engineers to write, test, and validate control logic offline on a PLC emulator.
- The feature-rich Data Monitoring Tool that allows users to quickly diagnose logic or performance issues using plotted data from a PLC or the Simulator.
- Optimized connectivity via a new high-performance OPC-UA Server that accelerates PLC communication performance along with PROFINET enhancements that support improved communications with I/O, VFDs and more.

Visit our Customer Care Center to view the release notes that provide a complete list of updates and/or to download the latest version.
